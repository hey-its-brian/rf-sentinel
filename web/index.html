This browser can't talk to USB devices. Use Chrome or Edge on a desktop computer. Open this page over HTTPS to install.

The radios. CC1101, nRF24, GPS, optional SX1262, plus the C5's own dual-band Wi-Fi.

STEPS

  1. Plug the board into this computer with a USB-C data cable.
  2. Click the matching INSTALL and pick its port. The CYD shows up as a CH340 serial device, the C5 as a USB JTAG/serial device.
  3. Confirm, wait for the progress bar, done. The board restarts into RF Sentinel.
  4. Repeat for the other board, then wire them together (see the wiring doc).

No port? CYD: hold BOOT while plugging in. C5: hold the button on G28 while plugging in.

GOOD TO KNOW

  • Installing erases the whole flash on that board.
  • Nothing here transmits. The node firmware has no transmit path and the build breaks if one is added.
  • Pin map, module wiring and power are in docs/wiring.md.
  • The node talks the same $RFS text protocol over USB, so a laptop works as a host too: open the port at 115200 and watch.

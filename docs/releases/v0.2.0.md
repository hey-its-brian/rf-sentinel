First release that has been on hardware (CYD host).

**Host (CYD 2.8")**
- UI restyled in the DECK//OS visual language: NETRUNNER palette, chamfered panels and chips, `// SECTION` headings, Orbitron chrome.
- SET page: the four DECK//OS accent themes (NETRUNNER, ARASAKA, NOMAD, MILITECH), brightness, node sweep rate, touch recalibration. All saved to NVS.
- Touch calibration on first boot; hold the screen or BOOT during the splash to redo it.
- Local Wi-Fi scan fixed: first scan at 3 s, 300 ms per channel, BLE duty cycle lowered so the shared radio gets Wi-Fi time.
